AstraeaOS WP is a combined open-source distribution built on WordPress. Different parts of the tree retain different license scopes.

The full text is available in [`AGPL-3.0.txt`](AGPL-3.0.txt) and at the repository root as `LICENSE`.

This includes, in particular, the original Astraea kernel and first-party subsystems under `astraea-core/`, the autonomous recovery layer under `astraea-recovery/`, Astraea-specific administration/installer assets, and other original Astraea additions.
