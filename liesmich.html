AstraeaOS WP

WordPress without the Plugin Stack.

AstraeaOS WP ist eine unabhängige, sicherheitsorientierte WordPress-Distribution mit einem integrierten First-Party-Kernel.

Alpha: Diese Software gehört zur Alpha-Reihe. Zuerst in einer Staging-Umgebung testen und Recovery/Backups verifizieren.

Installation

Entpacke die Runtime-Distribution in ein leeres Webroot, lege eine Datenbank an und öffne /wp-admin/install.php. Der Secure-Genesis-Assistent übernimmt Datenbank-, Identitäts- und Sicherheitsinitialisierung.

Systemanforderungen

PHP 8.3+ (64 Bit), MySQL 8.0+ oder MariaDB 10.11+, sowie json, hash, sodium, openssl, mbstring, intl, dom und mysqli oder pdo_mysql.
