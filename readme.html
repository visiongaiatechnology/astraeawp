AstraeaOS WP

WordPress without the Plugin Stack.

AstraeaOS WP is an independent, security-first WordPress distribution with an integrated first-party kernel.

Alpha: This software is part of the alpha series. Test in staging first and verify backup/recovery procedures.

Installation

Extract the runtime distribution into an empty webroot, create a database, and open /wp-admin/install.php. Secure Genesis guides database, identity and security initialization.

System requirements

PHP 8.3+ (64-bit), MySQL 8.0+ or MariaDB 10.11+, plus json, hash, sodium, openssl, mbstring, intl, dom and mysqli or pdo_mysql.
